## 素材选择与真实性
- 历史品牌屋 `brand-house.webp`、联合活动 `joint-giveaway.webp`、官方 M3 产品图片、展会匿名照片与已有视频是当前可用的真实/历史代表素材。
- 以前的两张 Gemini 节庆物料存在产品结构或优惠字样问题；不重新放入封面或作品墙。
- 新增的促销 KV 为文字信息层级与配色排版，用于说明营销主题、目标、版位和渠道适配；不声明历史刊发、真实折扣、制作产量或活动 ROI。
- Halloween 内容为原有选题策划，SEO 经营数据另作分时间窗口呈现。
- CRM 以英文邮件内容、受众与流程规则为展示重点，不将迁移/规划等同邮件系统上线。
- 源仓保留逐案例真实文档边界，避免公开客户名单、未确认的授权或敏感后台字段。

## 导航验收项目
1. `#/capabilities` 的全部能力链接必须进入正确案例及确切章节，不能只到案例顶部。
2. `#/case/operations` 四张 Tab 可以点击，`aria-selected` 与对应面板显隐同步。
3. `#/case/brand` 视觉入口进入真实素材章节；Review 视觉图库不使用 concept-01/02/03。
4. `#/case/seo` Halloween 目录和 SEO/PR 能力展示均可访问。
5. `#/case/creator` 筛选、Brief、审核、授权可读，关联视频可点开。
6. `#/experience` 四段任职均有职责、结果与作品入口。
7. 全部案例的“相关案例”不能循环跳回自身，也不能指向不存在的章节。
8. 源仓 public asset manifest 的大小和 SHA256 对齐发布文件。
9. GitHub Actions validate 与 preview deploy 都通过后，方可称为已上线预览。
10. 真正的桌面/移动端逐视口像素检查、视频播放/声音与肖像授权需要另外取得直接渲染/素材验收证据；代码回归不替代视觉播放测试。
