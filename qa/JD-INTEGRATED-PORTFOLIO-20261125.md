## 现有案例重组
1. **产品营销与新品上市**：用户洞察 → 四条产品线价值证明 → M3 Campaign 策划与上市物料 → 排期/团队审核。实际经历与五月策划方案不混写；不将 2025 Meta 汇总归因给 M3。
2. **品牌与整合传播**：品牌信息 → 黑五/母亲节/父亲节 KV → PR 与 Creator 协同 → SEO/EDM 内容承接。广告和商业授权由相应业务负责人负责。
3. **社媒增长与团队管理**：平台角色 → 内容矩阵与社群机制 → 季度/月度日历与审核 → Meta / Group 数据与问题反馈。平台、统计窗口、增长/快照分别保留。
4. **海外市场拓展与商业增长**：海外 B2B 客户分层与展会 → 线索/报价/成交 → 早期 Amazon Listing/PPC/经营复盘。不同任职年份、公司和业务结果不合并。
