# Huang Wenlin — Portfolio

Standalone static portfolio site for GitHub Pages.

- Entry: `index.html`
- No build step or third-party runtime dependencies.
- Images are optimized WebP assets; all paths are relative and work under the `/Enola-data/` project path.
- The GitHub Actions workflow deploys the repository root to GitHub Pages on pushes to `main`.

Portfolio content is anonymized where appropriate. Metrics retain source labels, windows, evidence status, and limitations; missing values are not converted to zero. Concept artwork is labeled as concept work, not historical campaign output.
